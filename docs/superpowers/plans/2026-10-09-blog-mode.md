# 書房與部落格兩種模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 網站分成「書房」（3D 房間）和「部落格」（傳統部落格）兩種模式，各自有一個 tab 切到另一邊；部落格新增「關於我」頁。

**Architecture:** 房間的導覽列（`src/pages/index.astro` + `src/scripts/study.js`）拿掉 `⋯` 選單，換成連到 `/archive/` 的「部落格」tab。
所有部落格頁共用的 `src/layouts/DeskLayout.astro` 把「← 回書房」和麵包屑換成刊頭 tab 列，並以 `tab` prop 決定亮哪個 tab；分頁標題的站名
改成 `site.config.yaml` 新增的 `blogTitle`。作者資料從 `src/lib/study.ts` 抽到 `src/lib/profile.ts`，房間和新的 `src/pages/about.astro` 共用。

**Tech Stack:** Astro 5（靜態輸出）、three.js（房間）、TypeScript、Notion API（build 時抓資料）、sharp（縮書封）、fontkitten（檢查字型子集）。

**Spec:** `docs/superpowers/specs/2026-10-09-blog-mode-design.md`

## Global Constraints

- 頁面內容（所有文章的年份列表、書架的木櫃、文章內頁）不改，只換頂部導覽。
- 部落格站名與分頁標題的站名：`保羅的學習筆記`（`site.config.yaml` 的 `site.blogTitle`）。書房（首頁）的分頁標題維持 `保羅的書房`。RSS 不改名。
- 三個 tab 依序：`所有文章`（`/archive/`）、`書架`（`/reading/`）、`關於我`（`/about/`）；隔開的 tab：部落格那邊是 `我的書房`（`/`），書房那邊是 `部落格`（`/archive/`）。
- 關於我不放房間自畫像卡片上的成就摘要（「出了《…》、兩度拿下 iThome 鐵人賽佳作…」），房間的卡片照舊保留。
- 書封來源：`https://cf-assets2.tenlong.com.tw/products/images/000/227/268/original/9786264140010_bc.jpg?1731661559`，縮成寬 360px 存成 `public/assets/my-book-cover.jpg`。
- 每個 task 完成時 commit 到 `master`（commit 訊息照 repo 的 `feat(room): …` / `feat(site): …` 風格，結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`）。
- **不要 push**，等使用者要求。Task 2 之後部落格 tab 會連到 `/about/`，Task 4 完成前 push 會讓那個 tab 變成 404。
- 指令都在 repo 根目錄執行。`npm run build` 會向 Notion 抓資料，需要 `.env` 的 `NOTION_API_KEY`。`$SCRATCH` 指 repo 以外的暫存資料夾（本 session 用 scratchpad）。
- 這個 repo 沒有測試框架。每個 task 的「測試」是：`npm run build` 成功，加上對 `dist/` 的檢查指令，再用 preview（`.claude/launch.json` 的 `astro-preview`，
  port 4322，供應 `dist/`）在瀏覽器裡確認。

## Review Focus

1. **最窄的手機（320px）上的房間底部列**：多了「部落格」一格，六格都要排得下，不能出現水平捲動。→ Task 1 Step 6。
2. **部落格刊頭在 320px 與 641–760px**：320px 時第二行的三個 tab 加「我的書房」要擠得下；641–760px 時一行排完，而且左右要跟紙張邊緣對齊（書架頁是較寬的 `desk-wide`）。→ Task 2 Step 9。
3. **鍵盤操作**：用 Tab 鍵移到房間的「部落格」時要出現 ▶ 游標，移到部落格的 tab 和「我的書房」時要有焦點外框。→ Task 1 Step 6、Task 2 Step 9。
4. **從部落格按瀏覽器「上一頁」回到房間**：房間要恢復，或重新跑一次開門動畫，不能卡在「推開書房的門……」。→ Task 2 Step 9。

- [ ] **Step 1: 寫檢查腳本 `scripts/check-blog-nav.mjs`**

```js
// Checks every blog page in a build: the blog's name ends its title, and exactly one tab is lit, the one its kind of page sits
// under. The room (index.html) keeps the site's own name. Run after `npm run build`: node scripts/check-blog-nav.mjs [dist]
import fs from 'node:fs';
import path from 'node:path';
import { parse } from 'yaml';

const dist = process.argv[2] ?? 'dist';
const { site } = parse(fs.readFileSync('site.config.yaml', 'utf8'));

// the tab a page sits under, by where it is: the book notes under the bookshelf, everything else that is written under all articles
const expected = (rel) => (rel === 'about/index.html' ? 'about' : rel.startsWith('reading/') ? 'reading' : 'archive');

const pages = [];
(function walk(dir) {
  for (const e of fs.readdirSync(dir, { withFileTypes: true })) {
    const p = path.join(dir, e.name);
    if (e.isDirectory()) walk(p);
    else if (e.name === 'index.html') pages.push(path.relative(dist, p).split(path.sep).join('/'));
  }
})(dist);

const problems = [];
const titleOf = (html) => html.match(/<title>([^<]*)<\/title>/)?.[1] ?? '';
let checked = 0;
for (const rel of pages) {
  if (rel === 'index.html' || rel.startsWith('study/')) continue; // the room, and the bare bodies the room fetches
  checked++;
  const html = fs.readFileSync(path.join(dist, rel), 'utf8');
  const title = titleOf(html);
  if (!title.endsWith(` | ${site.blogTitle}`)) problems.push(`${rel}: title "${title}"`);
  const lit = [...html.matchAll(/data-tab="(\w+)"[^>]*aria-current="true"/g)].map((m) => m[1]);
  if (lit.length !== 1 || lit[0] !== expected(rel)) problems.push(`${rel}: lit [${lit.join(', ')}], expected ${expected(rel)}`);
  if (/class="(desk-hud|crumbs)"/.test(html)) problems.push(`${rel}: still has the old HUD or crumbs`);
}
const roomTitle = titleOf(fs.readFileSync(path.join(dist, 'index.html'), 'utf8'));
if (roomTitle !== site.title) problems.push(`index.html: title "${roomTitle}", expected "${site.title}"`);

if (problems.length) {
  console.error(problems.join('\n'));
  process.exit(1);
}
console.log(`ok: ${checked} blog pages`);
```
