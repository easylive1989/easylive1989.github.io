## 目標

再加第三個世界：日式的窗外配日式的房間。窗外是雪中的湖，用浮世繪版畫的畫法；房間是和室，人坐在榻榻米上。

成功的樣子：鴨子點到第三下時，畫面讀起來是一間看得到雪景的和室，書桌是矮桌、吉利睡在座椅上；另外兩個世界和現在一模一樣；
三個世界裡能點的東西、四個角落的鏡頭都一樣能用。

## 不做的事

- 不做 demo 裡另外兩種窗外（春・富士、秋・夕暮），也不照季節換。
- 不改室內的燈光去配雪天或夜晚；環境反射沿用現有的。
- 書架、展示架、電視的高度不動。只有書桌、椅子、邊桌下沉。
- 不提供直接選世界的介面；仍然只有鴨子。
- 西式書房、中式書齋和它們的窗外都不動。

## 三個世界

| 世界 | 窗外 | 房間 |
|---|---|---|
| `lake`（預設） | 秋天湖景 | 西式書房 |
| `ink` | 水墨山水 | 中式書齋 |
| `snow`（新增） | 雪見 | 和室 |

- 鴨子三間輪流：`lake` → `ink` → `snow` → `lake`。提示文字維持「換個景色」。
- `localStorage` 的 `study-scenery` 多一個值 `snow`；認不得的值一律當 `lake`。
- 開門只建當下那間；第一次切到還沒建的那間就重放開門；建過的留著，之後瞬間切換。和前一份 spec 相同，只是從兩間變三間。
- 載入失敗：門重新打開在原本那間並跳 toast；下一次點鴨子還是試同一間。

## 雪見的窗外

形狀、顏色以定案的 demo 為準：`src/scripts/wa-demo.js` 裡 `yuki` 那一組（未進版控的暫時檔，網址加 `?wa` 可看）。

- **畫法**：浮世繪版畫。平塗、每塊形狀上緣一條輪廓線、天空由上往下暈染、幾條橫的霞。
- **構圖沿用湖的版面**：水面從 55% 往下、高地在左邊，所以棧橋、近處的水、門那一側鏡像的畫都和另外兩張一樣接得上。
- **主景畫得低**：和室的鴨居比西式的窗低，畫面上方從房間中央看不到。遠山、小島、茅屋都畫在水面上方約 100 px 以內
  （1024 × 600 的畫布），並放在右邊開間從中央看得到的那一段（橫向 40%–70%）。
- **內容**：灰藍的天、遠處的雪山、左岸積雪的丘和松、離岸一座小島，島上一間屋頂積雪、窗裡點著燈的茅屋和幾棵雪松，
  湖上一艘小船，整張畫面上散著雪點。門那一側的畫不畫小島和船。
- **顏色**：天 `#46566a` → `#7b8894` → `#c5cbd0`、輪廓線 `#26323d`、遠山 `#f2f4f4` → `#a9b8c4`、丘 `#e6eaec`／`#bcc8cf`、
  水 `#5d7284` → `#22303d`、霞 `#e4e8ea`、燈 `#f2c86b`。
- **飄的東西是雪**：白色，落得比落葉慢、左右飄得少、顆粒小一點（速度約落葉的一半）。

## 和室的樣子

形狀、尺寸、顏色以定案的 demo 為準：`src/scripts/wa-demo.js` 的 `buildWa()`。以下列出關鍵決定。

### 原則：支撐面跟著自己的那一組，整組可以下沉

前一份的原則是「支撐面不動，骨架換掉」。這次放寬一步：**書桌、椅子、邊桌三組各自整組往下沉**，組裡的東西（筆電、稿紙、自畫像、
系列書；坐墊和吉利；書堆）跟著一起下去，彼此的相對位置完全不變。書架、展示架、電視那三組不動。

| 組 | 下沉 | 結果 |
|---|---|---|
| 書桌 | 0.44 m | 桌面從 0.785 降到 0.345，是座卓的高度 |
| 椅子 | 0.375 m | 坐墊底貼著座椅的座板，座板貼著榻榻米 |
| 邊桌 | 0.32 m | 台面從 0.62 降到 0.30 |

下沉只在這個世界生效；切到別的世界就還原。

### 殼

| 部位 | 做法 |
|---|---|
| 地 | 榻榻米：2 m × 1 m 一張，每排錯開半張，長邊有深色的緣 |
| 牆 | 聚樂土牆 `#cbbd95`（灰泥的浮凸和粗糙度，不疊色圖），左右牆只到後牆為止 |
| 柱與長押 | 檜木方柱（12 cm）立在後牆兩角和中間、右牆對著兩處、兩個前角；長押沿牆一圈，高度和鴨居同 |
| 天花 | 木板加竿緣（12 根），四周一圈回緣 |
| 後牆 | 鴨居在 2.05 m，上面是小壁，下面是敷居。分兩個開間（x −2.88 到 −0.1、0.02 到 2.88），各四扇障子，中間兩扇推到外側兩扇後面，所以每間開一半 |
| 障子 | 木框、3 × 8 的組子、下面一段腰板；紙會透光（自發光） |
| 緣側 | 後牆外一條 58 cm 深的木地板，比棧橋高 2 cm，棧橋從它接出去 |
| 前牆 | 通往屋裡的門是兩扇襖，圓形的引手 |
| 左牆前段 | 一幅掛軸，寫「日々是好日」 |
| 牆腳與牆頂 | 淡的接觸陰影（和中式書齋同樣的濃度） |

鴨子的點擊判定：左邊開間推開的那一段（中間兩扇的寬度、鴨居以下）。

### 家具

## 程式結構

### `src/scripts/studySnowRoom.js`（新增）

和室的全部幾何、材質、畫布（榻榻米、障子、掛軸）。介面和另外兩間相同，多兩個可有可無的欄位：

```js
export default function buildSnowRoom(kit) // → { parts, opening, sink, lamp }
```

- `sink`：`{ desk, chair, side }`，這間房間擺出來時那三組各自下沉幾公尺。沒給就是 0。
- `lamp`：`{ at:[x, y, z], power }`，檯燈的光和光暈在書桌那一組座標裡的位置，以及光的強度。沒給就是西式檯燈燈罩的位置、強度 `0.8`；行燈離桌面近，用 `0.4`。
- 骨架是照「已經下沉之後」的樣子建的：例如座卓的腿只有 0.295 m 長，建在桌面下方，等整組沉下去剛好站在地上。

動態 `import()`，自己一個 chunk；靜態部件照舊 `weld`。

### `study.js` 的改動

- **世界多一個，鴨子照順序輪**：`WORLDS.snow`，加一個順序表；`turnWorld` 取「下一個」；開頁時記住的值只要在表裡就用它。
- **下沉**：`show()` 把書桌、椅子、邊桌三組的高度設成當下這間的 `sink`。
- **原本寫死在書桌高度的東西改成跟著書桌那一組**：桌面上的四塊接觸陰影、檯燈的點光源和它的光暈，改掛在書桌那一組底下（那一組在原點，
  所以座標不變）；`show()` 再把光和光暈移到當下這間的 `lamp`。dock 的「書桌」角落，鏡頭對準的點跟著那一組的下沉量走。
- **飄的東西可以每個世界不一樣**：世界多一個可有可無的 `fall`（速度、左右飄的幅度、顆粒大小），迴圈和材質用當下世界的值。
- 把書或稿紙拿到眼前的動作本來就是用世界座標算的，下沉不影響。

### `studyTextures.js`

多兩個畫圖函式：`paintSnowView(c, { seed, islet, feather })`、`paintSnowWater(c, view)`，寫法比照水墨那兩個。

## 出錯時

沿用前一份：載不下來就把門重新打開在原本那間，toast 請訪客重新整理；開頁時失敗就改開湖景。建到一半丟錯會把已掛上的部件拆掉。
新增一點：房間換走時，下沉、燈的位置、飄的東西都要還原成那一間自己的值，不能留著上一間的。

## 驗證

- 加入第三個世界之前和之後，`lake` 與 `ink` 各自看得到的物件清單（種類、名字、材質、頂點數、位置）必須完全相同。
- `snow` 世界：四個 dock 角落都飛得到，其中「書桌」對準的是沉下去之後的桌面；書、十件展品、筆電、自畫像、稿紙、系列書、電視都點得開；
  吉利在座椅上；拿起一張稿紙和一本系列書，會到眼前、放得回去。
- 桌面上的陰影和行燈的光暈貼著沉下去的桌面，不浮在半空。
- 鴨子：三間依序輪流；`snow` 只能從左邊推開的那一段點到；從 `snow` 切走之後，書桌、椅子、邊桌回到原本的高度，落葉恢復原本的速度。
- 停在 `snow` 重新整理：門打開直接是和室，場景裡沒有另外兩間的東西。
- 全新訪客：network 裡沒有 `studySnowRoom`，直到輪到它。
- 輕量模式、手機寬度各看一次；console 沒有錯誤；`npm run build` 和 `npm run check:nav` 通過。

## 實作順序

每一步做完都能在房間裡看到，另外兩個世界在每一步之後都必須完好。

1. **舞台準備**：房間介面的 `sink`、`lamp`；桌面陰影、檯燈的光與光暈改掛在書桌那一組；dock 的書桌角落跟著走；世界的 `fall`；鴨子照順序表輪。
   這一步做完，`lake` 和 `ink` 的外觀不變。
2. **雪見的窗外**：兩個畫圖函式、`WORLDS.snow`（房間先只有一片地板）、雪的落法。鴨子變成三間輪流。
3. **和室的殼**：榻榻米、牆、柱與長押、天花、障子、緣側、襖、掛軸、牆上的接觸陰影、鴨子的點擊判定。
4. **本棚與床脇**。
5. **座卓和桌上的東西**（行燈、盆栽、木框、書立、茶），書桌那一組下沉。
6. **電視台、座椅、矮台**，椅子和邊桌兩組下沉。
7. **收尾**：輕量模式與手機檢查、刪掉 demo 和 `study.js` 最後一行的 hook、`build-design.mjs` 與 `SKILL.md`、README。
