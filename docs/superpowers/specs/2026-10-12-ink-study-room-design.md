# 水墨山水的中式書齋 設計文件

日期：2026-10-12
影響範圍：`src/scripts/study.js`、新增 `src/scripts/studyWestRoom.js`、新增 `src/scripts/studyInkRoom.js`、`src/scripts/studyTextures.js`、
`src/scripts/studyWorker.js`、`src/pages/index.astro`、`.claude/skills/sync-claude-design/`（`build-design.mjs`、`SKILL.md`）、`README.md`

## 目標

點橡皮鴨把窗外換成水墨山水之後，房間還是西式書房（深色牆、格子窗、木門框），兩者不搭。要讓水墨山水有一間配得上它的房間：
不是換貼圖或加濾鏡，而是把房間的殼和家具換成中式書齋。

成功的樣子：切到水墨時，整個畫面讀起來是一間臨水的中式書齋；切回湖景時，西式書房和現在一模一樣；兩邊能點的東西、四個角落的鏡頭都一樣能用。

## 不做的事

- 不動西式書房和秋天湖景的任何外觀。
- 不加水墨濾鏡或描邊，材質維持現在的寫實畫法。
- 不搬動任何能點的東西（書、展品、筆電、稿紙、自畫像、電視、主機），也不動吉利和書堆的位置；鏡頭、dock、面板、閱讀器都不改。
- 不另外做一張中式房間用的環境反射圖；沿用現有的。
- 不讓房間和窗外各自切換；兩者永遠成對。
- 切走之後不釋放剛才那間：建過的房間留在記憶體裡，之後再切回去是瞬間的。

## 兩個世界

| 世界 | 窗外 | 房間 |
|---|---|---|
| `lake`（預設） | 秋天湖景 | 西式書房（現狀） |
| `ink` | 水墨山水（現狀） | 中式書齋（新增） |

- 橡皮鴨照舊負責切換，提示文字維持「換個景色」。
- `localStorage` 的 `study-scenery` 沿用，值不變：`ink` 現在代表「水墨山水＋中式書齋」。
- 窗外的畫、房間、落葉顏色在同一格換完，不會出現「水墨配西式書房」的過渡畫面。

### 只建看得到的那間

- **開門時只建當下這個世界的房間。** 另一間的幾何、材質、貼圖都不建：預設訪客不建中式書齋，也不下載它的程式；上次停在水墨的訪客不建西式的
  牆、窗、家具骨架，也不畫西式才用得到的大張貼圖（木地板、灰泥的色圖）。
- **第一次切到還沒建的那間，重放開門動畫。** 畫面回到那扇關著的門，房間在門後建好（建構、畫貼圖、編譯 shader），門再照開頁時的三段推開，
  鏡頭從門口走進去。
- **兩間都建過之後，切換是瞬間的**，不再回到門。

## 中式書齋的樣子

形狀、尺寸、顏色以定案的 demo 為準：`src/scripts/inkroom-demo.js`（未進版控的暫時檔）。實作時把內容寫進正式模組，再刪掉 demo。以下列出關鍵決定。

### 原則：支撐面不動，骨架換掉

層板高度、桌面高度、櫃面位置和西式書房完全相同，所以展品不需要兩套座標。中式家具只是換掉撐住這些面的骨架。

### 殼

| 部位 | 做法 |
|---|---|
| 牆 | 白粉牆 `#ece7da`，不疊灰泥色圖（只留法線和粗糙度），左右牆只到後牆為止 |
| 地 | 50 cm 青灰方磚，深色磚縫 |
| 天花 | 淺色望板，兩根大樑（z = −0.7、1.3），19 根椽子，四周牆頂一圈枋 |
| 柱 | 深色圓柱立在石柱礎上，都在右牆：兩個牆角，和對著兩根樑的位置。左牆沒有：後角是博古架，前角是板門 |
| 後牆左半 | **月洞門**：圓心 (−1.45, 0.92)、半徑 1.05，被地面截出約 1 m 寬的門檻；青磚門套比牆面凸出；石門檻 |
| 後牆右半 | **檻窗**：開口和現在的窗一樣（x 0.05–2.65、y 1.0–2.5），分四扇，外側兩扇是冰裂紋花窗，中間兩扇敞開 |
| 門窗之間 | 一幅墨竹立軸 |
| 前牆 | 對開板門，銅門鈸和門環 |
| 左牆前段 | 兩幅立軸：一幅山水，一幅寫「學而時習之　不亦說乎」 |

棧橋、鴨子、窗外的畫、湖面都不動。

### 家具

| 西式書房 | 中式書齋 | 留在原位的東西 |
|---|---|---|
| 書櫃（背板、側板、檐口、LED 燈條） | **書格**：每個開間前後各一根方材立柱，沒有背板和側板，底層牙板；層板同高 | 所有書、分類銅牌 |
| 展示架＋對開門櫃＋嵌燈 | **博古架**：四根立柱、四層同高，加三道錯開的立板和右下一階小格；下櫃是圓銅面葉的對開門 | 所有展品 |
| 抽屜書桌 | **畫案**：桌面同尺寸，腿內縮，長牙條加牙頭，兩端各兩根橫棖 | 筆電、稿紙、系列書 |
| 檯燈 | 掛在燈架上的六角紙燈，燈罩中心和原本的燈罩同一點 | 燈光和光暈 |
| 虎尾蘭 | 紫砂盆裡的蘭花 | — |
| 自畫像的銅框邊和支架 | **插屏**：木框加兩隻站腳 | 自畫像本身 |
| 書擋、筆 | 同尺寸的木書匣；筆換成筆筒、硯台、擱在筆架上的毛筆 | 系列書 |
| 柚木電視櫃 | **矮几**：四腿、三層板（高度同原本的頂板、層板、底板） | 電視、主機、手把、卡帶、線 |
| 布面扶手椅 | **圈椅**：馬蹄形椅圈、靠背板；坐面和原本一樣大 | 坐墊、吉利 |
| 邊桌 | **方几**：束腰、四腿、四面橫棖；几面同高 | 書堆 |

純擺設（不可點）：博古架右下那格的青瓷瓶、桌上的筆筒硯台毛筆。

木頭一律用中式自己的兩個深色材質（紫檀色 `#45251a`、較深的 `#2e1812`），不去改兩間共用的木頭材質顏色。展品自己的底座維持原色。

## 程式結構

三個檔案，一個舞台、兩間房間：

| 檔案 | 責任 |
|---|---|
| `src/scripts/study.js` | 舞台：renderer、鏡頭、工具函式、共用材質、兩間都有的東西（書、展品、桌上的筆電稿紙、電視主機、坐墊、吉利、棧橋、鴨子、窗外的畫、燈光）、UI、點擊、迴圈，以及「世界」的切換與開門 |
| `src/scripts/studyWestRoom.js`（新增） | 西式書房專屬的東西：牆地天花、窗、門框、前牆角落、家具骨架、檯燈、盆栽、嵌燈光暈、牆上的接觸陰影。程式是從 `study.js` 原封不動搬過來的 |
| `src/scripts/studyInkRoom.js`（新增） | 中式書齋專屬的東西 |

### 房間的介面

兩個房間模組長得一樣：

```js
export default function build(kit) // → { parts, opening }
```

- `kit`：`study.js` 交進來的工具（`THREE`、`box`、`cyl`、`mk`、`rod`、`std`、`pbr`、`ctex`、`sheet`、`roomUV`、`weld`、`decal`、`halo`…）、
  共用材質和貼圖、父群組（`room`、`shelf`、`disp`、`desk`、`rack`、`tvc`、`chair`、`side`、`portrait`、`pf`）和兩間共同遵守的尺寸
  （`LV`、`bays`、`DL`、`DW`、`DD`、`DX`、`DY`、`DZ`、`CW`、`CH`、`CD`、`WIN`、`DOOR`、`FDOOR`…）。
- `parts`：它加進場景的所有物件。家具骨架加進對應的父群組，和展品共用座標。切換世界就是把兩邊 `parts` 的 `visible` 對調。
- `opening(x, y)`：後牆平面上的一點是否落在通往棧橋的開口裡，給鴨子的點擊判定用（西式是矩形門洞，中式是月洞門）。
- 房間模組不 import `study.js`，只吃 `kit`。

中式書齋的靜態部件照房間現有的做法 `weld` 成每種材質一個 mesh。

### `study.js` 的改動

- **搬走西式專屬的建構程式**，只留兩間共用的尺寸常數（門、窗的位置）。
- **大張貼圖按需要畫。** `paintSheets(low, keys)` 只畫指定的幾張；`study.js` 只畫「目前為止被要走、還沒畫」的那些。木地板和灰泥色圖由西式書房自己要，
  所以從水墨開門時不會被畫。
- **世界。** 原本的 `SCENERY`／`setScenery` 擴成 `WORLDS`：每個世界有窗外的畫，和一個建房間的函式（西式是靜態 import 的 `buildWestRoom`，
  中式是 `import('./studyInkRoom.js')`，Vite 會切成自己的 chunk）。`prepare(name)` 建房間並畫窗外，`show(name)` 把它擺出來、另一間收起來。
- **開門。** 開頁時 `prepare` 上次停留的世界、`show`、畫貼圖、編 shader，然後走進去。切換時若目標世界還沒建：關門 → 同一套流程 → 再開門；已建過就直接 `show`。
- **鴨子的點擊判定**改成問當前世界的 `opening`。

### `index.astro`

門的 CSS 加兩個狀態，讓它可以重放：一個讓門瞬間回到關著的樣子（不倒著播一次開門），一個讓畫面快速暗回門前（原本的淡出有延遲，是給第一次開門用的）。

### 同步與文件

- `build-design.mjs` 和 `SKILL.md`：同步到 Claude Design 的腳本從三個變五個（多 `studyWestRoom.js`、`studyInkRoom.js`），逐位元組複製。
- `README.md`：`src/scripts/` 的檔案樹加兩行。

## 出錯時

- 切換時中式書齋的 chunk 載不下來（離線、部署剛換版）或 15 秒沒回應：門重新打開在原本的世界，toast 說一聲，`localStorage` 不改。
- 開頁時上次停在 `ink` 但載入失敗：改開湖景和西式書房，不卡在門口；`localStorage` 不改，下次再試。
- 門關著的期間擋掉對房間的點擊，也不接受第二次切換。

## 驗證

沒有單元測試框架，靠實際開起來檢查：

- **搬家沒有改到西式書房**：搬之前和搬之後，各把場景裡每個看得到的物件（種類、名字、材質、頂點數、位置）列成清單，兩份必須完全相同。
- 兩個世界 × 一般／輕量模式 × 桌機／手機寬度：四個 dock 角落都飛得到，書、展品、筆電、自畫像、電視點得開，吉利出現在椅子上。
- 全新訪客（清掉 `localStorage`）：場景裡沒有中式的物件，network 裡沒有 `studyInkRoom`；點鴨子 → 回到門 → 門打開是中式書齋；再點 → 瞬間回湖景，沒有門。
- 停在水墨後重新整理：門打開直接是中式書齋，場景裡沒有西式的牆、地板、窗、家具骨架；點鴨子 → 回到門 → 門打開是西式書房。
- 鴨子：兩個世界都只能從門洞的視線點到。
- 載入失敗（暫時讓建中式書齋的函式丟錯）：兩條出錯路徑都如上所述。
- console 沒有錯誤，`npm run build` 通過。

## 實作順序

每一步做完都能在房間裡看到，西式書房在每一步之後都必須完好。

1. **把西式書房搬出去**：`studyWestRoom.js`、`kit`、按需要畫貼圖。外觀不變（用物件清單比對）。
2. **兩個世界與開門**：`WORLDS`、只建當下那間、切換時重放開門、出錯處理；中式書齋先只有一片地板。
3. **中式的殼**：地、牆、天花樑椽、柱、月洞門、檻窗、三幅立軸、板門、牆上的接觸陰影。
4. **書格**。
5. **博古架**（含青瓷瓶）。
6. **畫案**和桌上的東西（紙燈、蘭花、插屏、書匣、筆硯）。
7. **矮几、圈椅、方几**。
8. **收尾**：手機與輕量模式檢查、刪掉 demo、`build-design.mjs` 與 `SKILL.md`、README。
